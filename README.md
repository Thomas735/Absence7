# 🚀 Absence7 - Guide d'Installation

Bienvenue sur **Absence7**, votre application de suivi d'absences et de gestion d'emploi du temps.

## 📋 Prérequis

Avant de commencer, vous devez installer **Node.js** sur votre ordinateur. C'est le moteur qui permet de faire tourner l'application.

1.  Allez sur le site officiel : [nodejs.org](https://nodejs.org/)
2.  Téléchargez la version **LTS** (Recommended for Most Users).
3.  Installez-le en suivant les instructions par défaut.

---

## 🛠️ Première Installation

Une fois vous avez récupéré le projet (via git ou téléchargement zip) :

1.  Ouvrez le dossier du projet.
2.  Si vous êtes sur **Windows** :
    *   Faites un clic droit dans le dossier > "Ouvrir dans le terminal" (ou PowerShell).
    *   Tapez la commande suivante et appuyez sur Entrée :
        ```bash
        npm install
        ```
3.  Si vous êtes sur **Mac / Linux** :
    *   Ouvrez un terminal.
    *   Naviguez vers le dossier du projet (`cd chemin/vers/le/dossier`).
    *   Tapez la commande suivante et appuyez sur Entrée :
        ```bash
        npm install
        ```

*Cette étape n'est nécessaire que la toute première fois pour télécharger les bibliothèques.*

---

## ▶️ Lancer l'Application

### 🖥️ Pour Windows
Double-cliquez simplement sur le fichier :
👉 **`start_windows.bat`**

### 🍎 Pour Mac / Linux
Double-cliquez sur le fichier :
👉 **`absence7.command`**

*(Si cela ne fonctionne pas sur Mac, faites un clic droit > Ouvrir, ou lancez-le via le terminal).*

---

## 💡 Utilisation
Une fois l'application lancée, votre navigateur s'ouvrira automatiquement sur `http://localhost:3000`.

1.  **Créez un compte** lors de la première visite.
2.  **Importez votre emploi du temps** (fichier .ics) ou utilisez le calendrier par défaut.
3.  **Gérez vos absences** en cliquant sur les cours.
